## Shape, scale and materials

The farm is a warm, cozy, chunky toy diorama: slightly rounded masses, a few
broad flat-shaded facets, deliberate small irregularities and no random noise.
Prioritise the silhouette and 3–5 identity features over decoration. At
1280×720 the game renders the world at 320×180 then enlarges it to 4 CSS pixels
per world pixel. Use parts at least 0.1 units thick, normally with a readable
0.3×0.3 face; only explicitly labelled cleats or bands may be thinner. Do not
put hairline grain, text, tiny nails, separate leaves, textures or bitmap art on
assets. Use opaque flat-shaded matte materials (roughness 1, metalness 0);
water/glass may be 0.25–0.7. No new lights, baked lighting or shadow maps.

Reference scales from actual code: character capsule 1.4 high, radius 0.4;
placement tile 1.5; existing fence 1.47×0.17×0.95; cottage walls 4.4×3×2,
chimney top 3.6; coop body 1.4×1.3×1.1 with a raised floor and ramp; signed
tree approximately 2.8 high. Look Dev's 3–4-unit tree guidance is a design
target for *new* trees, not a measurement of the existing tree.

Every recipe has a base-centred origin at (0,0,0), +Y up, and front +Z. Its
declared footprint and height must agree within 10% with both the spec and the
built bounds. Nothing may sit below -0.02; every part must connect to the
ground or another connected part. Face direction is a semantic claim: numerical
checks cannot prove a door or handle actually faces +Z.

## Closed recipe vocabulary

The runtime source of truth is declarative JSON: a named part, primitive,
dimensions, transform, palette token and identity-feature tag. No arbitrary
code, external assets, URLs, textures, or raw colour hexes in recipes. Allowed
primitives: `box`, `bevelBox`, `cylinder`, `cone`, `sphere` (faceted
icosahedron detail 0–1), `capsule`, `wedge`, `lathe` and `extrude`. A bounded
`custom` BufferGeometry array is an explicit lower-trust escape hatch, never
an exemption from checks or human review. At most 40 parts; no nonuniform
transform scale above 1:3. Optional jitter must specify a seed and stay within
0.03 units/radians. Use enough separation or overlap to avoid coplanar faces;
an explicitly declared polygon offset is recorded and subject to review.

Allowed albedo tokens are defined in `src/assets/palette.ts` using the exact
game constants from `src/scene/farmPalette.ts` and
`src/scene/farmBuildingMaterials.ts`. They include `foliage.mid/light/dark`,
`trunk`, `wood.light/mid/dark`, `timber`, `door`, `dirt`, `dirt.edge`,
`dirt.hi`, `plaster`, `roof`, `roof.band`, `stone`, `glass` and
`water`, `water.rim`, `water.deep`. They can be resolved through named slots
for later retinting. The separate `legacy` tokens reproduce existing signed
decorations, not a general permission to invent colours. Look Dev's named
accent list is an explicit extension: at most one accent per asset; its source
and reason must be recorded in the palette module. Unapproved `proposedTokens`
must not build. No pure black, pure white or neon palette additions.

Signed references to retrieve: `src/scene/createFarmLayout.ts` (trees),
`src/scene/createCottage.ts`, `src/scene/createRampCoop.ts`,

## Stages, checks and review

Run blockout, form, palette/material, detail, in-scene lighting and optimisation
in that order. Every stage requires H1–H10 before fixed-camera render feedback
and an independent OpenCode critic. A rendered identity feature that cannot be
seen is a blocker even if the overall score is high. A pixel-difference test can
measure the visible contribution of tagged parts, but **cannot prove that a
tag is truthful**; the vision critic and human must judge semantic identity.
Fixed renders use eight 45-degree yaws, three game light phases and grass,
path and void backgrounds. Each frame has a hash. EBR-80 must be integrated
before interpreting lighting direction, night appearance or style fit as final.

| Hard gate | Meaning |
| --- | --- |
| H1 | Closed schema, allowed primitives and palette tokens. |
| H2 | Part and triangle budgets. |
| H3 | Bounds and metadata within 10% of the brief. |
| H4 | Base-centred origin, ground contact and declared +Z front. |
| H5 | Minimum feature thickness/readable face, with explicit band/cleat exceptions. |
| H6 | Two builds have identical geometry/material hashes. |
| H7 | No overlapping near-coplanar faces within 0.005, except declared polygon offset. |
| H8 | All parts connected to each other or ground. |
| H9 | Nothing below -0.02. |
| H10 | Collision footprint is 90–130% of the declared footprint. |

Soft checks include at least 40 changed pixels per silhouette at game scale;
contrast against grass/path/void of at least 1.15 luminance ratio or a
meaningful hue difference; key-light/three-step value agreement, night glow,
scene scale and style distance. These are design floors, not measurements or
proof of quality. The vision critic's separate session scores silhouette,
palette, shape language, value structure, scene fit and craft 1–5 and names
blockers/fixes. If image reading or critique fails, the report must say
**visual critique not run**; a numeric-only check is not a visual pass.

At most five candidate rounds, with bounded corrections per stage and globally.
Record `continue`, `refine-spec`, `refine-code`, `request-input` or `stop`,
source/recipe, checks, renders, critique and the best-so-far candidate. The
best candidate remains `needs-human`; it is never a signed pass or a game
asset until Look Dev signs it after EBR-80. An independent critic is not
independent artistic approval.

Return **JSON data**, not TypeScript or code. Every part must use a palette
token and may tag exactly one declared identity feature. Use several parts
with the same feature tag if that feature needs several components. The checker
tests each feature's visible contribution in eight fixed daytime views.

```json
  "origin": "base-center",
  "facing": "+Z",
  "parts": [
    { "name": "body", "prim": "box", "size": [1, 1, 1], "at": [0, 0.5, 0], "mat": "wood.mid", "feature": "body" }
  ],
  "anchors": {},
  "emissive": [],
  "collision": { "type": "box", "w": 1, "d": 1, "h": 1 },
  "slots": {},
  "tags": ["farm", "cozy"]
}
```

Primitive fields (all position/dimension units are world units; rotations are
Euler **degrees**; dimensions are full widths):

* `box` / `bevelBox`: `size:[width,height,depth]`; optional `bevel` on bevelBox.
* `cylinder`: `radiusTop`, `radiusBottom`, `h`, `segments` (3–24; both radii positive).
* `cone`: `radius`, `h`, `segments` (3–24); the builder makes a nondegenerate tip.
* `sphere`: faceted icosahedron, `radius`, `detail` (0 or 1).
* `capsule`: `radius`, `length` (straight middle), `segments`.
* `wedge`: `size:[width,height,depth]`.
* `lathe`: `profile:[[radius,localY],...]` ordered from bottom to top, `segments`.
  A zero-radius endpoint is supported. For a closed barrel, use e.g. axis point,
  base rim, middle bulge, top rim, axis point. The local y values are relative
  to `at`, not absolute world coordinates.
* `extrude`: `polygon:[[x,y],...]`, `depth` along Z.
* `custom`: `positions` and triangle `indices`; lower-trust, only when necessary.

Each part needs `name`, `prim`, `mat`, `at`; optional `rot`, `scale`, `feature`,
`exception` (`band` or `cleat` only), `polygonOffset`, and seeded `jitter`.
No loops, calculations, expressions, URLs, comments, raw hexes, arbitrary keys,
or code. Matte albedo tokens include `wood.mid`, `wood.light`, `timber`,
`trunk`, `foliage.mid`, `foliage.light`, `foliage.dark`, `dirt.hi`, `stone`,
`plaster`, `roof` and `water`. `slots` can map aliases to these tokens.

The checker uses actual 3D triangle intersection, so intersect adjacent parts by
more than 0.005 units; avoid coincident exterior faces and thin decorative
plates. A valid component must be connected to ground through other components.
Do not use identical X/Z extents on intersecting stacked boxes: their side faces
become coplanar. For a band around a cylinder, use a lathe profile rather than a
solid cylinder if it would hide the body. Use broad readable geometry; do not
claim a feature merely by naming an invisible or irrelevant part.

import * as THREE from 'three';
import type { EmissiveAccent } from '../lighting/createPracticalLights';
import { GROUND_HEIGHT } from './createIsland';
import { BUILDING_PALETTE, createBuildingPane, type BuildingMaterials } from './farmBuildingMaterials';
import { buildingFootprint, type CoopSpec } from './farmBuildingSpecs';
import { createGableRoof } from './createGableRoof';

function box(parent: THREE.Group, name: string, width: number, height: number, depth: number,
  material: THREE.Material, x: number, y: number, z: number) {
  const mesh = new THREE.Mesh(new THREE.BoxGeometry(width, height, depth), material);
  mesh.name = name;
  mesh.position.set(x, y, z);
  parent.add(mesh);
  return mesh;
}

export function createRampCoop(parent: THREE.Group, spec: CoopSpec, materials: BuildingMaterials) {
  const { name, x, z, width, depth, height, floorHeight, roofRise, roofOverhang, rampWidth, rampLength } = spec;
  const coop = new THREE.Group();
  coop.name = `farm-${name}`;
  coop.position.set(x, GROUND_HEIGHT, z);
  parent.add(coop);

  // The lock's dark stub posts and lighter timber wall trim are distinct.
  for (const sideX of [-1, 1]) for (const sideZ of [-1, 1]) {
    box(coop, `${name}-post`, 0.3, floorHeight, 0.3, materials.posts,
      sideX * (width / 2 - 0.15), floorHeight / 2, sideZ * (depth / 2 - 0.15));
  }
  box(coop, `${name}-body`, width, height, depth, materials.coopWall, 0, floorHeight + height / 2, 0);
  for (const side of [-1, 1]) {
    box(coop, `${name}-corner-trim`, 0.14, height, 0.1, materials.timber,
      side * (width / 2 - 0.07), floorHeight + height / 2, depth / 2 - 0.05);
    box(coop, `${name}-eave-trim`, width, 0.12, 0.1, materials.timber,
      0, floorHeight + height - 0.06, side * (depth / 2 - 0.05));
  }
  createGableRoof(coop, {
    name, width, depth, wallTop: floorHeight + height, rise: roofRise, overhang: roofOverhang,
    wallMaterial: materials.coopWall, roofMaterial: materials.shingle,
  });

  const front = depth / 2;
  box(coop, `${name}-pop-hole`, 0.4, 0.5, 0.1, materials.popHole, 0, floorHeight + 0.25, front - 0.05);
  const glowGeometry = new THREE.BoxGeometry(0.2, 0.25, 0.1);
  glowGeometry.translate(0, 0, -0.05);
  const glow = new THREE.Mesh(glowGeometry, createBuildingPane(BUILDING_PALETTE.popHole));
  glow.name = `${name}-pop-hole-glow`;
  glow.position.set(0, floorHeight + 0.25, front);
  coop.add(glow);

  // Extrude a triangular wedge so the visible ramp and its X/Z box agree.
  const rampShape = new THREE.Shape();
  rampShape.moveTo(-front, 0);
  rampShape.lineTo(-front, floorHeight);
  rampShape.lineTo(-(front + rampLength), 0);
  rampShape.closePath();
  const rampGeometry = new THREE.ExtrudeGeometry(rampShape, { depth: rampWidth, bevelEnabled: false });
  rampGeometry.rotateY(Math.PI / 2);
  const ramp = new THREE.Mesh(rampGeometry, materials.ramp);
  ramp.name = `${name}-ramp`;
  ramp.position.x = -rampWidth / 2;
  coop.add(ramp);

  const angle = Math.atan2(floorHeight, rampLength);
  for (let distance = 0.25; distance < rampLength; distance += 0.25) {
    const cleat = box(coop, `${name}-ramp-cleat`, rampWidth, 0.1, 0.1, materials.cleats,
      0, floorHeight * (1 - distance / rampLength) + Math.cos(angle) * 0.05,
      front + distance + Math.sin(angle) * 0.05);
    cleat.rotation.x = angle;
  }
  const extraEmissives: EmissiveAccent[] = [{ material: glow.material, strength: 0.7 }];

  return {
    extraEmissives,
    obstacles: [
      buildingFootprint(`${name}-body`, x, z, width, depth),
      buildingFootprint(`${name}-ramp`, x, z + front + rampLength / 2, rampWidth, rampLength),
    ],
    splashExclusion: buildingFootprint(`${name}-roof`, x, z, width + roofOverhang * 2, depth + roofOverhang * 2),
  };
}

// Both the ghost and the placed object come from this same geometry and palette.
export function createPlacementVisual(kind: PlacementKind) {
  const group = new THREE.Group();
  group.name = `placement-${kind}-visual`;

  if (kind === 'fence') {
    const wood = new THREE.MeshStandardMaterial({ color: FARM_PALETTE.barnWood, roughness: 1 });
    const trim = new THREE.MeshStandardMaterial({ color: FARM_PALETTE.barnTrim, roughness: 1 });
    const postGeometry = new THREE.BoxGeometry(0.17, 0.95, 0.17);
    for (const x of [-0.65, 0.65]) {
      const post = new THREE.Mesh(postGeometry, trim);
      post.position.set(x, 0.475, 0);
      group.add(post);
    }
    const railGeometry = new THREE.BoxGeometry(1.4, 0.13, 0.1);
    for (const y of [0.32, 0.67]) {
      const rail = new THREE.Mesh(railGeometry, wood);
      rail.position.set(0, y, 0.08);
      group.add(rail);
    }
  } else {
    const edge = new THREE.MeshStandardMaterial({ color: FARM_PALETTE.dirtEdge, roughness: 1 });
    const dirt = new THREE.MeshStandardMaterial({ color: FARM_PALETTE.dirt, roughness: 1 });
    const base = new THREE.Mesh(new THREE.BoxGeometry(TILE_SIZE * 2 - 0.06, 0.1, TILE_SIZE - 0.06), edge);
    base.position.y = 0.05;
    group.add(base);
    const surface = new THREE.Mesh(new THREE.BoxGeometry(TILE_SIZE * 2 - 0.2, 0.04, TILE_SIZE - 0.2), dirt);
    surface.position.y = 0.11;
    group.add(surface);
    const furrowGeometry = new THREE.BoxGeometry(TILE_SIZE * 2 - 0.32, 0.025, 0.13);
    for (const z of [-0.4, 0, 0.4]) {
      const furrow = new THREE.Mesh(furrowGeometry, edge);
      furrow.position.set(0, 0.142, z);
      group.add(furrow);
    }
  }
  return group;
}

export function makeGhost(group: THREE.Group) {
  const materials = new Set<THREE.MeshStandardMaterial>();
  group.traverse((object) => {
    if (!(object instanceof THREE.Mesh)) return;
    const meshMaterials = Array.isArray(object.material) ? object.material : [object.material];
    for (const material of meshMaterials) {
      if (!(material instanceof THREE.MeshStandardMaterial) || materials.has(material)) continue;
      materials.add(material);
      material.transparent = true;
      material.opacity = 0.5;
      material.depthWrite = false;
    }
    object.renderOrder = 2;
  });
}

export function disposePlacementVisual(group: THREE.Object3D) {
  const geometries = new Set<THREE.BufferGeometry>();
  const materials = new Set<THREE.Material>();
  group.traverse((object) => {
    if (!(object instanceof THREE.Mesh)) return;
    geometries.add(object.geometry);
    for (const material of Array.isArray(object.material) ? object.material : [object.material]) materials.add(material);
  });
  geometries.forEach((geometry) => geometry.dispose());
  materials.forEach((material) => material.dispose());
  group.removeFromParent();
}

function faceDetail(parent: THREE.Group, name: string, width: number, height: number,
  material: THREE.MeshStandardMaterial, x: number, y: number, z: number, rotation = 0): WindowPane {

  mesh.name = name;
  mesh.position.set(x, y, z);
  mesh.rotation.y = rotation;
  parent.add(mesh);
  return mesh;
}

export function createCottage(parent: THREE.Group, spec: CottageSpec, materials: BuildingMaterials) {
  const { name, x, z, width, depth, height, roofRise, roofOverhang } = spec;
  const cottage = new THREE.Group();
  cottage.name = `farm-${name}`;
  cottage.position.set(x, GROUND_HEIGHT, z);
  parent.add(cottage);

  const baseHeight = 0.25;
  box(cottage, 'cottage-stone-base', width, baseHeight, depth, materials.stone, 0, baseHeight / 2, 0);
  box(cottage, 'cottage-walls', width, height - baseHeight, depth, materials.plaster,
    0, (height + baseHeight) / 2, 0);
  for (const sideX of [-1, 1]) for (const sideZ of [-1, 1]) {
    box(cottage, 'cottage-corner-post', 0.16, height - baseHeight, 0.16, materials.timber,
      sideX * (width / 2 - 0.08), (height + baseHeight) / 2, sideZ * (depth / 2 - 0.08));
  }
  for (const side of [-1, 1]) {
    box(cottage, 'cottage-eave-beam', width, 0.12, 0.12, materials.timber,
      0, height - 0.06, side * (depth / 2 - 0.06));
  }

  createGableRoof(cottage, {
    name, width, depth, wallTop: height, rise: roofRise, overhang: roofOverhang,
    wallMaterial: materials.plaster, roofMaterial: materials.cottageRoof, bandMaterial: materials.shingle,
  });

  const chimneyTop = 3.6;
  const chimneyBottom = height + roofRise - roofRise / (depth / 2) * (0.7 + 0.225) - 0.1;
  box(cottage, 'cottage-chimney', 0.45, chimneyTop - chimneyBottom, 0.45, materials.stone,
