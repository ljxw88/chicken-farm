Port map
--------
- Placement tool state, occupied tiles, undo ordering, placed objects and fence
  collision footprints are plain Miniplex entities in src/placement/
  placementSystem.ts. The engine input mapper dispatches placement actions at
  event time, ahead of click-to-move; fixed-tick one-shots remain independent.
- src/placement/createPlacementAdapter.ts resolves the existing ground rays
  and decorative bounding boxes, mirrors entity state to the existing visuals
  and UI, and exposes placed-fence collisions in the existing scene/QA array.
  Walking and placement query the same engine obstacle entities. Plots reserve
  cells but stay walkable. Touch/pen preview before the direct Place control.
- The clock, URL hold, weather mode and transition envelopes live in engine
  components and full-elapsed-frame systems in src/environment/. The existing
  lighting and rain drivers render those values in their original order.
  Console phase, cycle and weather setters/getters and pixel hooks remain.
- Character movement retains its 0.1-second clamp. Pixel pass, scene, camera,
  light, shadow, rain visuals and all look settings stay as on 5d9ba48.
- Deletion: src/placement/createPlacement.ts and its old gameplay arrays/maps,
  DOM listeners and synchronous controller. The placement view no longer owns
  click handlers. Old clock/weather closure state and startup hold were removed;
  the adapters use the shared state rather than a second implementation.
