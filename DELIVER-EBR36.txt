Behavior and fitting
- The app configures the existing cycle to 1,440 seconds (24 minutes); createDayNightCycle itself retains its existing 72-second default for independent callers. The footer reads the actual configured duration, including console overrides.
- Time chevrons select real lighting presets and pause following. Follow the day resumes from the actual current progress without counting suspended time spent paused. The displayed phase and toolbar sun/moon use the nearest preset while lighting continues to interpolate.
- Weather shows Pending / Awaiting EBR-35, with both chevrons and Let it change disabled. The neutral dotted indicator does not claim a weather condition. Sound and extra options are disabled because their systems are not present; fullscreen uses the real browser API and is disabled when unsupported.
- src/ui/tokens.css records provisional fitting values for font, color, blur, sizes and spacing; they are not locked or a claim of pixel-perfect matching. The reference viewport used for desktop verification was 1260x1080.

Run and click through
1. Run `npm ci`, then `npm run dev -- --host 127.0.0.1` in this worktree and open Vite's printed URL.
2. The lower-centred panel starts open. Click the time chevrons: the scene changes and Follow the day switches off. From Morning, the previous chevron wraps to Night, lighting the barn windows and lantern.
3. Turn Follow the day back on to resume. For a quick demonstration, with it on, run `setDayNightCycleSeconds(4); setDayNightPhase('sunset')` in the browser console and watch the toolbar change to the moon. The footer changes to 4 seconds; reload restores 24 minutes.
4. Close with X and reopen with the toolbar sun/moon. Keyboard users can Tab to controls, use Enter/Space and Escape, and retain focus after closing. WASD still walks even when a HUD button has focus; click/tap uncovered ground to walk, including while the panel is open. Barn, tree and pond blockers remain active.
5. Try expand to enter/exit fullscreen on supported browsers. Weather, sound and more options remain visibly unavailable. In short landscape viewports the panel itself scrolls.
