Run and inspect
- `npm install && npm run dev`, then open the URL Vite prints. The current local production preview is http://127.0.0.1:5189/ while its preview process is running.
- The cycle starts at morning and runs continuously: daytime at 18s, sunset at 36s, night at 54s, then morning at 72s. Values morph smoothly between these phase points.
- In the browser console, use `setDayNightCycleSeconds(12); setDayNightPhase('morning')` to see all four phases in 12 seconds, or inspect each immediately:
    setDayNightPhase('morning')
    setDayNightPhase('daytime')
    setDayNightPhase('sunset')
    setDayNightPhase('night')
  For a longer look at any phase, first use `setDayNightCycleSeconds(3600)`. The cycle keeps running after selecting a phase.
- Hold WASD or click/tap the ground to walk; the orthographic isometric camera follows. Walk toward a ground edge to see the sky: the ground fills the initial view. The two sheds are visual stubs, not movement obstacles.

API and locked look
- `window.setDayNightCycleSeconds(n)` (also exported by `src/main.ts`) sets the full cycle duration in seconds; finite positive values only. Changing it preserves progress, and the default is 72 seconds. The object returned by `createDayNightCycle` exposes the same method for a future HUD.
- `window.setDayNightPhase(name)` accepts `morning`, `daytime`, `sunset` or `night` and applies that phase immediately.
- All sky, fog, ambient, hemisphere, directional, window and lantern lighting knobs use the supplied Look Dev LOCKED presets in `src/lighting/dayNightPhases.ts`; only their transitions are interpolated. Window distance is 7 and lantern distance is 3.5, both with decay 2. No postFX changes; GridHelper opacity remains unchanged.
