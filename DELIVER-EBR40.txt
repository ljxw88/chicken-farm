Nest READY — no console needed
1. From this worktree run `npm ci` and then `npm run dev -- --host 127.0.0.1 --port 5173 --strictPort`. Open http://127.0.0.1:5173/ or use the equivalent Nest scene origin.
2. Append `?weather=clear|cloudy|rain&phase=morning|daytime|sunset|night` to that origin, choosing one value from each list. Examples:
   http://127.0.0.1:5173/?weather=clear&phase=daytime
   http://127.0.0.1:5173/?weather=cloudy&phase=daytime
   http://127.0.0.1:5173/?weather=rain&phase=daytime
   http://127.0.0.1:5173/?weather=clear&phase=night
   http://127.0.0.1:5173/?weather=cloudy&phase=night
   http://127.0.0.1:5173/?weather=rain&phase=night
3. Wait about 2 seconds for the weather fade. A valid URL phase remains fixed for comparison; omit `phase` for the normal running cycle. Invalid values are ignored independently. The existing `setWeather` / `getWeather` console APIs remain available; either day/night console setter resumes a URL-pinned cycle.
4. Clear has the exact phase lighting and no rain. Cloudy has softer, cooler lighting and no rain. Rain retains the existing gentle streaks and splashes. At night the barn windows and carried lantern stay warm. Walk with WASD or click the ground; barn, tree and pond collisions remain active.
